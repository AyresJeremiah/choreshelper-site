Chores that run themselves, on your own server.

ChoresHelper is a self-hosted household chore tracker. Your family's data stays on a small server in your home, with an iPhone and iPad companion app and a wall-display board for the kitchen.

Get the iPhone and iPad app Set up your server

The app is distributed as an Unlisted App Store app, so it does not appear in App Store search. The button above works for anyone who has the link; otherwise ask your household admin for it. The app is free. It connects to a ChoresHelper server that you run yourself, so you will need one before signing in. You can also try a built-in demo household in the app with no server at all.

What it does

  • Recurring choresDaily, weekly or custom schedules, assigned to the people in your household.
  • Family accountsParents manage everything; kids see and complete their own chores.
  • AllowanceTrack a weekly allowance per person, with the policy your household chooses.
  • Wall-display boardAn always-on view of everyone's chores for a tablet in the kitchen.
  • Home remindersOptional on-device reminders when you arrive home with chores still to do.
  • Private by designNo cloud account, no analytics, no tracking. Works on a home network with no internet.

How it fits together

  1. Run the ChoresHelper server at home (a Raspberry Pi or any small Linux machine) using Docker Compose.
  2. Install the app on your iPhone or iPad and connect it to the server on your home network.
  3. Sign in with the account your household admin created for you.
